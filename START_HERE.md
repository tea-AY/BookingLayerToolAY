A **complete web application** that connects your Bookinglayer retreat bookings to Asana via a fully customizable marketing workflow - all in a single HTML file!

- 🔗 **Direct Bookinglayer Integration** - Fetches retreats automatically
- 🎨 **Fully Customizable** - Add, edit, remove any marketing task
- 📊 **Smart CSV Export** - Asana-compatible format with auto-calculated dates
- 🌐 **No Installation** - Works in any browser
- 🚀 **Deploy Anywhere** - GitHub Pages, Netlify, or just open locally
- 📱 **Mobile Friendly** - Works on all devices
- 🔐 **100% Secure** - All processing happens in your browser

## 🚀 Quick Start (3 Steps)

### 1. Deploy the App

**Easiest: Open Locally**
- Just open `index.html` in Chrome, Firefox, or Safari
- That's it! No server needed.

**Best: Deploy to GitHub Pages (Free)**
- See `DEPLOY_GUIDE.md` for step-by-step instructions
- Get a permanent URL to share with your team
- Takes 5 minutes

### 2. Get Your Bookinglayer API Token

1. Log into [Bookinglayer](https://app.bookinglayer.io)
2. Go to **Settings** → **API** → **Tokens**
3. Click **"Create New Token"**
4. Copy the token

### 3. Use the App

1. Open the app (locally or deployed URL)
2. Enter your Bookinglayer token
3. Click "Fetch Retreats"
4. Customize your marketing tasks
5. Download CSV
6. Import to Asana

**Done!** All your retreats now have complete marketing workflows.

## 🎯 How It Works

### Step 1: Connect to Bookinglayer

The app connects to your Bookinglayer account via API and fetches:
- All your retreat packages

- Retreat names and locations

**No manual data entry required!**

## 🎨 Customization Examples

### Add a TikTok Campaign

1. Open "Pre-Launch Tasks"
2. Click "+ Add Custom Task"
3. Fill in:
   - Name: `📱 Create TikTok Teaser`
   - Channels: `TikTok`
   - Days before: `40`
   - Description: `Create 15-60 second TikTok showcasing retreat vibes`
   - Pillar: `EXPLORE`
4. Click ✓ to save

### Change Email Timing

1. Find "📧 Early Bird Email Campaign"
2. Click ✏️ (edit icon)
3. Change "Days Before Retreat" from `45` to `60`
4. Click ✓ to save

### Add Your Own Channels

Edit any task to include:
- TikTok
- Pinterest
- LinkedIn
- YouTube
- Newsletter
- SMS/Text
- Your custom channels

### Disable Tasks You Don't Need

Simply uncheck the task - it won't be included in the CSV export.

## 🆘 Troubleshooting

### "Failed to fetch retreats"
- ✅ Check API token is correct
- ✅ Verify token hasn't expired
- ✅ Ensure internet connection
- ✅ Check Bookinglayer account has retreats

### CSV Import Issues
- ✅ Map columns correctly in Asana
- ✅ Check CSV opens in Excel/Sheets first
- ✅ Verify dates are YYYY-MM-DD format

### Tasks Not Appearing in Asana
- ✅ Confirm CSV uploaded successfully
- ✅ Check column mapping
- ✅ Verify task dates aren't in past
