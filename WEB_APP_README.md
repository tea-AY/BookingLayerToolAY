- Download CSV
- Import to Asana

## 🎯 What This Does

### Connects to Bookinglayer
✅ Fetches all your retreat schedules automatically
✅ Pulls dates, locations, retreat names

### Creates Marketing Workflows
✅ 25+ tasks per retreat (fully customizable)
✅ Organized by: Pre-Launch, Promotional, Pre-Retreat, During, Post-Retreat
✅ Auto-calculates due dates based on retreat dates

### Exports to Asana
✅ Generates perfect CSV format
✅ One milestone per retreat
✅ All tasks with descriptions and channels
✅ Ready to import in seconds
